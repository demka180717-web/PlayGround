## GoreBox: Physics Sandbox

A self-contained browser game built with Canvas and vanilla JavaScript. Open `index.html` or serve this folder with any static web server.

### Controls

- **WASD / arrow keys** — move; **Space / W / Up** — jump
- **Left click** — use the selected tool; **right click** — spawn a random prop
- **1–5** — select pistol, gravity gun, spawn tool, eraser, or pause
- **Q** — open/close the welcome menu; **R** — reset the chamber
- On touch screens, use the on-screen movement and action buttons

Spawn props and training dummies, shoot to knock objects around, grab and launch props with the gravity gun, and reset the room whenever you want.
